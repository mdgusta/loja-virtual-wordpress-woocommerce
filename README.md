LOJA VIRTUAL DE PRODUTOS DIGITAIS
-

Projeto de criação e configuração de um e-commerce utilizando WordPress, com foco na comercialização de produtos digitais e na experiência do usuário.

SOBRE O PROJETO
-

Este projeto consiste na criação de uma loja virtual utilizando WordPress e ferramentas de construção visual, desde a configuração do domínio e da hospedagem até a estruturação da loja, personalização das paáginas e configuração dos recursos de comerécio eletrônico.

O objetivo foi construir uma plataforma para comercializar produtos digitais, com uma interface organizada, navegação intuitiva e estrutura preparada para oferecer uma experiência de compra simples e acessível.

TECNOLOGIA E FERRAMENTAS
-

- WordPress: sistema de gerenciamento de conteúdo (CMS) utilizado como base do site.
- WooCommerce: gerenciamento da loja virtual, cadastro de produtos e estrutura de vendas.
- Elementor Pro: contrução e personalização visual das páginas e componentes do site.
- Hostiger: registro de domínio e hospedagem do site.
- UOL Host: configuração e gerenciamento de e-mails corporativos.

FUNCIONALIDADES E IMPLEMENTAÇÃO
-

- Estruturação das páginas institucionais e comerciais.
- Personalização visual da interface utilizando Elementor Pro.
- Configuração da loja virtual com WooCommerce.
- Organização do catálogo e das páginas de produtos.
- Configuração da infraestrutura de domínio e hospedagem.
- Configurações de e-mails corporativos vinculados ao negócio.
- Disponibilização de produtos digitais para os clientes.

PRINCIPAIS APRENDIZADOS
-

O desenvolvimento deste projeto proporcionou experiência prática na integração e configuração de diferentes ferramentas para criar uma solução de e-commerce, incluindo:

- Gerenciamento de conteúdo e estrutura de paginas.
- Configuração de uma loja virtual e seus recursos comerciais.
- Personalização de interfaces com ferramentas visuais.
- Configuração de domínio, hospedagem e e-mails corporativos.
- Organização e experiência do usuário durante a navegação e compra.

ARQUITETURA DA SOLUÇÃO
-

A plataforma foi organizada utilizando serviços e ferramentas com responsabilidades distintas:

Componentes      Responsabilidade
-
WordPress        Gerenciamento do site.
WooCommerce      Operação da loja virtual.
ElementorPro     Construção e personalização visual.
Hostinger        Domínio e Hospedagem.
UOL Host         E-mails corporativos.
